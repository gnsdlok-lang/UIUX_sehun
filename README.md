# 7주차 수정사항

# 선택이 어려운 사람을 위한 페이지

## 사용자와 목표
- 사용자 : 간단하지만 중요한 선택을 해야 하는 사람
- 목표 : 2진 랜덤 선택 항목을 설정하고, 2진 랜덤 값을 얻는다.

## 사용자 흐름
1. 랜덤 서약에 동의를 하고 "2진 랜덤 시작하기"를 누른다.
2. 랜덤 항목을 선택한다. 선택을 하지 않으면 안내를 받는다.
3. 항목의 이름(목적어)를 입력한다.
4. 설정을 확인하고 수정하거나 랜덤을 실행한다. 
5. 결과를 확인하고 수긍하거나, 다시 랜덤을 누른다.

## 인터렉션 시나리오
1. 랜덤 서약에 동의 안내
- 행동, 이벤트 : 기존 서약에 동의 체크박스를 선택하고 '랜덤 시작하기' 버튼을 클릭 한다.
- 조건 : 랜덤 서약 동의가 선택 되었는가?
- 반응, 다음 상태: 동의전에는 버튼을 누를 수 없다.
                    동의 후 선택시 안내 팝업이 뜬다.
                    팝업에서 "돌아가기"나 ESC를 누르면 동의를 해제하고 시작 화면으로 간다.
                    "동의 하고 시작하기"를 누르면 항목 선택이 뜬다.
2. 랜덤 항목 선택
- 행동, 이벤트 : 랜덤 항목 "한다/안한다", "산다/안산다", "먹는다/안먹는다" 항목을 선택하도록 하고, 선택항목으로 "추천하기" 체크박스를 넣는다.
- 조건 : 항목이 선택 되었는가?
- 반응, 다음상태 : 선택항목을 보여준다.
3. 항목의 목적어 입력
- 행동, 이벤트 : 입력을 받고 선택했던 항목과 합쳐서 보여준다.
- 조건 : 텍스트가 입력 되었는가?
- 반응, 다음상태 : 입력된 상태를 보여준다. 확인하기로 넘어가는 버튼이 생긴다.
4. 설정을 확인
- 행동, 이벤트 : 항목을 보고 "수정하기"나 "랜덤 실행"을 선택한다
- 조건: 수정인가, 완료인가?
- 반응, 다음 상태: 수정하면 기본 값을 유지하고 조건 선택으로 돌아간다.
                    완료하면 랜덤 실행으로 이동한다.
5. 결과를 확인
- 행동, 이벤트 : 결과를 확인하고 필요하면 "수정하기"나 "다시 랜덤"을 누른다.
- 반응, 다음 상태: 초기화 한다.
