# 중간고사 수정사항

# 선택이 어려운 사람을 위한 페이지

## 사용자와 목표
- 사용자 : 간단하지만 중요한 선택을 해야 하는 사람
- 목표 : 식사메뉴 선택에 도움을 준다

## 사용자 흐름
1. "식사고르기" 버튼을 누른다.
2. 팝업에서 식사, 회식 중에 선택을 한다.(Dialog)
3. 식사 선택을 확인 시켜주며 체크박스로 원하는 후보 항목을 선택한다.(후보:한식 중식 양식 일식)
4. 회식 선택을 확인 시켜주며 체크박스로 원하는 후보 항목을 선택한다.(후보:한식 중식 양식 일식)
5. 사진과 함께 결과만족에 하는지 묻는다. "<-항목변경" 버튼과 "다시 실행하기" "나가기" 버튼이 있다.
6. 나가기 선택시 팝업. 이미지와 선택결과를 저장할건지 물어본다.

## 인터렉션 시나리오
1. 식사메뉴 선택 버튼을 누른다.
- 행동, 이벤트 : 기존 이미지 아래 버튼에 "식사 고르기" 버튼을 클릭한다.
- 반응, 다음 상태: 식사 고르기 팝업창이 뜬다.

2. 팝업에서 식사, 회식 중에 선택
- 행동, 이벤트 : 팝업창이 발생하고 "메뉴 선정을 위해 식사 목적을 선택해주세요" 라고 텍스트가 뜨고
                식사, 회식 라디오 버튼이 생긴다. 버튼2개[취소 버튼, 다음(식사 선택하기) 버튼]
- 조건 : 라디오 버튼 항목이 선택 되었는가?
- 반응, 다음상태 : 선택을 하지 않으면 "목적을 선택해주세요" 경고문구가 뜨고 다음으로 넘어가지 않는다.

3. 식사 라디오 버튼 선택시
- 행동, 이벤트 : "원하는 항목만 선택해주세요" 라고 텍스트가 뜨고
                4개의 체크박스(한식, 중식, 양식, 일식)이 있고 체크박스를 누르면 아래에 문구로
                [00 00 항목이 선택되었습니다] 라고 알림을 준다.
                아래에 2개의 버튼[뒤로가기(목적변경) 버튼과 다음(랜덤 실행)]이 있다.
- 조건 : 체크박스가 선택 되었는가?
- 반응, 다음상태 : 선택을 하지 않으면 "항목을 선택해주세요" 경고문구가 뜨고 다음으로 넘어가지 않는다. 뒤로가기 버튼을 누르면 다시 2번으로 이동한다.

4. 회식 라디오 버튼 선택시
- 행동, 이벤트 : "원하는 항목만 선택해주세요" 라고 텍스트가 뜨고
                4개의 체크박스(한식, 중식, 양식, 일식)이 있고 체크박스를 누르면 아래에 문구로
                [00 00 항목이 선택되었습니다] 라고 알림을 준다.
                아래에 2개의 버튼[뒤로가기(목적변경) 버튼과 다음(랜덤 실행)]이 있다.
- 조건 : 체크박스가 선택 되었는가?
- 반응, 다음상태 : 선택을 하지 않으면 "항목을 선택해주세요" 경고문구가 뜨고 다음으로 넘어가지 않는다. 뒤로가기 버튼을 누르면 다시 2번으로 이동한다.

5. 사진과 함께 결과를 확인
- 행동, 이벤트 : 음식 사진과 항목이 표시된다. 버튼3가지 ["<-항목변경" 버튼과 "다시 실행하기" "나가기"]
- 반응, 다음 상태: 버튼에 따라 작용함.

6. 나가기 선택시 팝업
- 행동, 이벤트 : 팝업에 "결과를 저장하시겠습니까?" 버튼2가지[저장하기, 나가기]
- 조건 : 저장하기 선택시
- 반응. 다음상태 : 이미지와 메뉴가 저장됨. 팝업 닫힘.
